# OpenNetwork visual language

Use semantic roles for surfaces, text, fill, outlines, focus and status. The yellow brand mark is a
brand asset; text and interactive roles use their contrast-corrected tokens. Use the supplied
OpenNetwork mark without redrawing it. NDDev attribution links to <https://nddev.ai>.

Choose a theme from system settings or a persistent user preference. Offer light and dark variants
with increased contrast. Density changes layout metrics without changing meaning. Platform context
selects type sizes, font stacks and target sizes. Scale text with the platform and allow controls to
grow naturally around it.

Use the kit's text roles and scripts. IBM Plex Sans covers Latin and Cyrillic, including Kazakh;
IBM Plex Sans Arabic handles Arabic shaping. Arabic drops tracking and case transformations. Native
Chinese uses system CJK fonts; the web package includes Noto Sans SC. Font licenses travel with the
package and appear in the Flutter license registry.

Component definitions in kit/components record anatomy, state cues, keyboard behavior and platform
mapping. Use native controls where those mappings call for them. Products own content and layout;
new visual values belong in the canonical tokens.
