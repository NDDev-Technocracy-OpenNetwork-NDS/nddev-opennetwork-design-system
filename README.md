# OpenNetwork Design System

Tokens, web components, fonts and native packages for NDDev OpenNetwork products.
The public source is self-contained and generates every package without access to another repository.

OpenNetwork uses a yellow brand, neutral surfaces, IBM Plex typography and the original NDDev mark.
The four themes are light, dark, light contrast and dark contrast. Platform, density and motion are
independent settings; the web also follows system color, contrast and reduced-motion preferences.

| Package                                              | Contents                                                                                       |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `packages/web`                                       | CSS tokens, text styles, 33 component families, bundled web fonts and an interactive reference |
| `packages/flutter`                                   | Typed tokens, Material 3 bindings, icons and the existing OpenNetwork application API          |
| `packages/apple`                                     | Swift values and SwiftUI bindings                                                              |
| `packages/kotlin`                                    | Kotlin values and Compose Material 3 bindings                                                  |
| `packages/rust`                                      | Typed values, icons and optional bundled font bytes                                            |
| `packages/figma`                                     | Variables and text-style import payloads                                                       |
| `packages/fonts`, `packages/icons`, `packages/brand` | Assets with provenance and licenses                                                            |

The web kit implements the component markup, styles and reference interactions. Native packages
provide typed values, theme bindings and platform control mappings; they do not provide 33 new native
widget implementations. Applications retain their platform's semantics, keyboard behavior and layout.

For Flutter, pin this repository and use `packages/flutter`:

```dart
import 'package:nddev_opennetwork_design_system/opennetwork_design_system.dart';

final theme = OpenNetworkTheme.dark();
final accessible = OpenNetworkTheme.lightContrast(reduceMotion: true);
```

`OpenNetworkTheme`, `OpenNetworkColors`, spacing, radii, typography, sizes, motion and
`OpenNetworkBrand` remain available. The expanded typed API exposes platform, density, script and
contrast contexts. Canonical tokens live in `tokens/`, component specifications in `kit/` and Flutter
application bindings in `adapters/flutter/`. `tokens/tokens.json` is a generated compatibility view.

Source generation uses a Linux Git checkout with `flock` (util-linux), Node 24.22.1, Bun 1.4.3 and Flutter 3.47.7. Native packages are consumed on their target platforms without running the generator. Run `just install` and `just generate` to regenerate
outputs. `just check` verifies sources and generated bytes; `just test`, `just test-browser` and
`just platforms` run tests. `just serve` opens the reference at <http://127.0.0.1:4870>.
Each package includes its usage documentation and licenses.
